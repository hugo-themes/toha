# Documentation sources

The guides under content/docs were imported from [hugo-themes/toha-docs](https://github.com/hugo-themes/toha-docs/tree/bbff576b800bd9bf1b74088226ff65af08ddc87b), commit bbff576b800bd9bf1b74088226ff65af08ddc87b. Article author metadata and in-content credits are retained. The import ledger in imports/toha-docs.json records original paths, checksums, translations and old URLs; imported guides are maintained here from now on.

Adaptations include modern navigation weights, /docs/ routes with /posts/ aliases, language-aware links, current setup instructions, safe Markdown instead of inline templates, and current social shortcode names. Missing French featured-posts/category translations remain absent. The former empty external-menu example now contains an explicit external link.

The sample video is shared from the portfolio example: video by [Rahul Sharma](https://www.pexels.com/@rahul-sharma-493988) from [Pexels](https://www.pexels.com). The V3-to-V4 guide retains its attribution to Alexandre Neto and the original issue.

The documentation is organized into Hugo sections for layouts and shared topics. Moved page/resource targets and previous documentation URLs are recorded in the ledger; original source checksums and credits remain unchanged.
