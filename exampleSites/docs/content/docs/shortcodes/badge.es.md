Muestra una etiqueta pequeña con el tono neutral o accent.

Requiere una página moderna activada.

## Uso

```go-html-template
{{</* badge label="neutral" tone="neutral" */>}}
```

### Vista previa

{{< badge label="neutral" tone="neutral" >}}

## Variaciones: `accent`

```go-html-template
{{</* badge label="accent" tone="accent" */>}}
```
