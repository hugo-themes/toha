Inserta un gist de GitHub con los argumentos posicionales usuario, identificador y nombre de archivo opcional. Esto carga un script externo en el navegador.

Referencia de compatibilidad para sitios existentes. Los ejemplos se muestran como código fuente sin cargar recursos clásicos ni externos en la documentación moderna.

## Uso

```go-html-template
{{</* gist username gist-id file.go */>}}
```
