Intégrez une vidéo avec des contrôles natifs sur les pages modernes. La mise en page historique conserve son lecteur. Définissez src et, si nécessaire, le type MIME.

Disponible sur les pages historiques et modernes activées ; chacune utilise ses propres ressources.

## Utilisation

```go-html-template
{{</* video src="/videos/sample.mp4" type="video/mp4" */>}}
```
