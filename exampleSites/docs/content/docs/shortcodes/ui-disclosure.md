Use a native disclosure with a label and Markdown content. Set open="true" to expand it initially.

Requires an enabled modern page. See the component gallery for live examples.

## Usage

```go-html-template
{{</* ui-disclosure label="Details" */>}}
More information.
{{</* /ui-disclosure */>}}
```
