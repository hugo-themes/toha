Muestra texto plano con uno de los tipos permitidos: abbr, kbd, mark, sub o sup. title indica el significado de una abreviatura.

Requiere una página moderna activada. Consulta la galería de componentes para ver ejemplos.

## Uso

```go-html-template
{{</* ui-text kind="kbd" */>}}Esc{{</* /ui-text */>}}
```
