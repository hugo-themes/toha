Intégrez un gist GitHub avec les arguments positionnels utilisateur, identifiant et nom de fichier facultatif. Cela charge un script tiers dans le navigateur.

Référence de compatibilité pour les sites existants. Ces exemples sont affichés comme code source sans charger les ressources historiques ou tierces dans les docs modernes.

{{</* gist username gist-id file.go */>}}
