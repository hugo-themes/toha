Mensajes con los tonos info, success, warning o danger.

Disponible en páginas clásicas y modernas activadas; cada una usa sus propios recursos.

## Uso

```html
{{</* alert type="info" */>}}
**Markdown**: `code`.
{{</* /alert */>}}
```
