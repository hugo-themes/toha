Utilisez un bloc dépliable natif avec un libellé et du Markdown. open="true" l’ouvre par défaut.

Nécessite une page moderne activée. Consultez la galerie des composants pour les exemples.

## Utilisation

```go-html-template
{{</* ui-disclosure label="Details" */>}}
More information.
{{</* /ui-disclosure */>}}
```
