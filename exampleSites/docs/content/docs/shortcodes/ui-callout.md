Highlight Markdown content with an optional title and an info, success, warning, or danger tone.

Requires an enabled modern page. See the component gallery for live examples.

## Usage

```go-html-template
{{</* ui-callout title="Tip" tone="info" */>}}
Your message.
{{</* /ui-callout */>}}
```
