Générez des tailles adaptatives depuis une image locale dans assets avec src, alt et éventuellement sizes. Utilisez img pour les images de bundle sur les pages modernes.

## Utilisation

```go-html-template
{{</* rimg src="images/default-background.jpg" alt="Landscape" sizes="100vw" */>}}
```

### Aperçu

{{< rimg src="images/default-background.jpg" alt="Landscape" sizes="100vw" >}}
