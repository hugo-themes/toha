Générez des tailles adaptatives depuis une image locale dans assets avec src, alt et éventuellement sizes. Utilisez img pour les images de bundle sur les pages modernes.

Référence de compatibilité pour les sites existants. Ces exemples sont affichés comme code source sans charger les ressources historiques ou tierces dans les docs modernes.

## Utilisation

```go-html-template
{{</* rimg src="images/photo.jpg" alt="A landscape" sizes="100vw" */>}}
```
