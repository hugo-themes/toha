Affichez du texte brut avec l’un des types autorisés : abbr, kbd, mark, sub ou sup. title indique le développement d’une abréviation.

Nécessite une page moderne activée. Consultez la galerie des composants pour les exemples.

## Utilisation

```go-html-template
{{</* ui-text kind="kbd" */>}}Esc{{</* /ui-text */>}}
```
