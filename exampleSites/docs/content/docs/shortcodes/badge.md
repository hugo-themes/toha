Show a small label with neutral or accent tone.

Requires an enabled modern page.

## Usage

```go-html-template
{{</* badge label="neutral" tone="neutral" */>}}
```

### Preview

{{< badge label="neutral" tone="neutral" >}}

## Variations: `accent`

```go-html-template
{{</* badge label="accent" tone="accent" */>}}
```
