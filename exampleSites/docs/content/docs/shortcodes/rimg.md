Generate responsive sizes from a local image in assets using src, alt, and optional sizes. Use img for page-bundle images on modern pages.

Compatibility reference for existing sites. These examples are shown as source here and do not load legacy or third-party assets into the modern docs.

## Usage

```go-html-template
{{</* rimg src="images/photo.jpg" alt="A landscape" sizes="100vw" */>}}
```
