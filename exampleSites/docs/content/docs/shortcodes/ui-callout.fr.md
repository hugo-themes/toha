Mettez du Markdown en évidence avec un titre facultatif et le ton info, success, warning ou danger.

Nécessite une page moderne activée. Consultez la galerie des composants pour les exemples.

## Utilisation

```go-html-template
{{</* ui-callout title="Tip" tone="info" */>}}
Your message.
{{</* /ui-callout */>}}
```
