Genera tamaños adaptables de una imagen local en assets con src, alt y opcionalmente sizes. Usa img para imágenes de bundles en páginas modernas.

Referencia de compatibilidad para sitios existentes. Los ejemplos se muestran como código fuente sin cargar recursos clásicos ni externos en la documentación moderna.

## Uso

```go-html-template
{{</* rimg src="images/photo.jpg" alt="A landscape" sizes="100vw" */>}}
```
