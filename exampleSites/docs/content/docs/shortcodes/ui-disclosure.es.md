Usa un desplegable nativo con una etiqueta y contenido Markdown. open="true" lo abre inicialmente.

Requiere una página moderna activada. Consulta la galería de componentes para ver ejemplos.

## Uso

```go-html-template
{{</* ui-disclosure label="Details" */>}}
More information.
{{</* /ui-disclosure */>}}
```
