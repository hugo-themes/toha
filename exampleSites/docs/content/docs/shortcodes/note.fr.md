Créez une fiche avec un titre. Séparez les cartes internes par trois tirets. Son apparence dépend des styles historiques.

Référence de compatibilité pour les sites existants. Ces exemples sont affichés comme code source sans charger les ressources historiques ou tierces dans les docs modernes.

## Utilisation

```go-html-template
{{</* note title="Notes" */>}}
First note.

---
Second note.
{{</* /note */>}}
```
