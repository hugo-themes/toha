Créez un lien avec page ou href, ou une action désactivée. Les variantes sont primary, secondary et ghost. Un contrôle avec une icône seule doit garder un libellé.

Nécessite une page moderne activée. Consultez la galerie des composants pour les exemples.

## Utilisation

```go-html-template
{{</* ui-button label="Portfolio" page="/docs/portfolio" variant="secondary" */>}}
```
