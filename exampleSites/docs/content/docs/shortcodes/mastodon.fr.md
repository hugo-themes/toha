Intégrez un message Mastodon avec user et id, et éventuellement server. Le navigateur charge le message distant et son script.

Référence de compatibilité pour les sites existants. Ces exemples sont affichés comme code source sans charger les ressources historiques ou tierces dans les docs modernes.

## Utilisation

```go-html-template
{{</* mastodon server="mastodon.social" user="username" id="post-id" */>}}
```
