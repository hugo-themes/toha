Muestra el visor PDF clásico. Define src y opcionalmente renderPageNum y hidePaginator. El visor depende del JavaScript clásico.

Referencia de compatibilidad para sitios existentes. Los ejemplos se muestran como código fuente sin cargar recursos clásicos ni externos en la documentación moderna.

## Uso

```go-html-template
{{</* embed-pdf src="/files/document.pdf" renderPageNum="1" hidePaginator="false" */>}}
```
