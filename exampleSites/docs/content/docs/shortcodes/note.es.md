Crea una tarjeta de notas con un título. Separa las tarjetas internas con tres guiones. Su presentación depende de estilos clásicos.

Referencia de compatibilidad para sitios existentes. Los ejemplos se muestran como código fuente sin cargar recursos clásicos ni externos en la documentación moderna.

## Uso

```go-html-template
{{</* note title="Notes" */>}}
First note.

---
Second note.
{{</* /note */>}}
```
