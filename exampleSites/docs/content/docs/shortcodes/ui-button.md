Create a link using page or href, or a disabled action. Named variants are primary, secondary, and ghost. An icon-only control still needs a label.

Requires an enabled modern page. See the component gallery for live examples.

## Usage

```go-html-template
{{</* ui-button label="Portfolio" page="/docs/portfolio" variant="secondary" */>}}
```
