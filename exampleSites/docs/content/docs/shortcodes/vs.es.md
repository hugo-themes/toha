Añade espacio vertical en rem. Las páginas modernas aceptan de 0 a 12; usa el flujo normal del contenido cuando sea posible.

Disponible en páginas clásicas y modernas activadas; cada una usa sus propios recursos.

## Uso

```go-html-template
Before
{{</* vs 2 */>}}
After
```
