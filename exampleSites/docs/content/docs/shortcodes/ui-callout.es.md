Destaca contenido Markdown con un título opcional y el tono info, success, warning o danger.

Requiere una página moderna activada. Consulta la galería de componentes para ver ejemplos.

## Uso

```go-html-template
{{</* ui-callout title="Tip" tone="info" */>}}
Your message.
{{</* /ui-callout */>}}
```
