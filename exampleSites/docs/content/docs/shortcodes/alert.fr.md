Messages avec les variantes info, success, warning ou danger.

Disponible sur les pages historiques et modernes activées ; chacune utilise ses propres ressources.

## Utilisation

```go-html-template
{{</* alert type="info" */>}}
Your message.
{{</* /alert */>}}
```
