Crea un enlace con page o href, o una acción desactivada. Las variantes son primary, secondary y ghost. Un control de solo icono necesita una etiqueta.

Requiere una página moderna activada. Consulta la galería de componentes para ver ejemplos.

## Uso

```go-html-template
{{</* ui-button label="Portfolio" page="/docs/portfolio" variant="secondary" */>}}
```
