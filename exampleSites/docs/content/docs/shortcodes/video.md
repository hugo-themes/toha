Embed a video with native controls on modern pages. The legacy layout retains its existing player. Set src and optionally the MIME type.

Available in legacy and enabled modern pages; each uses its own markup and assets.

## Usage

```go-html-template
{{</* video src="/videos/sample.mp4" type="video/mp4" */>}}
```
