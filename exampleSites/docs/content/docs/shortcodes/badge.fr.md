Affichez un petit libellé avec le ton neutral ou accent.

Nécessite une page moderne activée.

## Utilisation

```html
{{</* badge label="neutral" tone="neutral" */>}}
```

### Aperçu

{{< badge label="neutral" tone="neutral" >}}

## Variantes: `accent`

```html
{{</* badge label="accent" tone="accent" */>}}
```

### Aperçu

{{< badge label="accent" tone="accent" >}}
