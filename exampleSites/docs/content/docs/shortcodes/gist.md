Embed a GitHub gist using positional user, gist ID, and optional filename arguments. This loads a third-party script in the reader’s browser.

Compatibility reference for existing sites. These examples are shown as source here and do not load legacy or third-party assets into the modern docs.

## Usage

```go-html-template
{{</* gist username gist-id file.go */>}}
```
